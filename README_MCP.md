# Dialogue Engine — MCP Server v2.0

**`mcp_server.py`** превращает Dialogue Engine в полноценный MCP-сервер,
позволяя AI-ассистентам (Antigravity, Claude Desktop, Cursor, Continue и др.)
читать, редактировать и экспортировать сценарии визуальных новелл через
стандарт [Model Context Protocol 2024-11-05](https://spec.modelcontextprotocol.io/).

Плагин **Live Watcher** (`reload_plugin.py`) мгновенно отображает изменения
ИИ на холсте редактора — **без перезапуска**.

---

## 🚀 Быстрый запуск

### Подключение (Antigravity / Claude Desktop / Cursor)

```json
{
  "mcpServers": {
    "dialogue-engine": {
      "command": "python",
      "args": ["d:/DE/mcp_server.py", "D:/projects/Violant/game/violant.json"],
      "env": { "PYTHONIOENCODING": "utf-8" }
    }
  }
}
```

> Если путь не передан, сервер автоматически ищет `violant.json` в стандартных местах.

## 🛠 Инструменты (Tools)

### Проект
| Инструмент | Описание |
|---|---|
| `de_load_project` | Загрузить / перезагрузить `.json` файл проекта |
| `de_save_project` | Сохранить граф на диск (с резервной копией) |
| `de_reload_server` | Перезапустить MCP-сервер (применить изменения кода) |

### Анализ
| Инструмент | Описание |
|---|---|
| `de_get_stats` | Сводная статистика: узлы, связи, типы, персонажи, листья |
| `de_get_characters` | Список персонажей с числом реплик и цветами |
| `de_find_leaf_endpoints` | Все конечные точки графа (где сюжет обрывается) |
| `de_get_node` | Полная информация по одному узлу |
| `de_search_nodes` | Поиск по тексту, персонажу или типу |
| `de_trace_branch` | Распечатать ветку сценария от узла |

### Создание узлов
| Инструмент | Описание |
|---|---|
| `de_add_story_node` | Добавить реплику персонажа или нарратив (`#Сцена`) |
| `de_add_choice_node` | Узел ветвящегося выбора игрока |
| `de_add_condition_node` | Логическое условие (вых. 0 = True, вых. 1 = False) |
| `de_add_music_node` | Узел музыки / звукового эффекта |
| `de_bulk_add_nodes` | Массовое создание узлов за один вызов |

### Редактирование
| Инструмент | Описание |
|---|---|
| `de_update_node` | Изменить текст, спикера, тип, координаты или `custom_data` |
| `de_move_node` | Переместить узел (абсолютно или на delta) |
| `de_duplicate_node` | Создать копию узла без связей |
| `de_delete_node` | Удалить узел и все его связи |

### Связи
| Инструмент | Описание |
|---|---|
| `de_connect_nodes` | Соединить выход одного узла со входом другого |
| `de_disconnect_nodes` | Удалить связь |

### Валидация и экспорт
| Инструмент | Описание |
|---|---|
| `de_validate_graph` | Проверить граф на ошибки и несоответствия |
| `de_export_renpy` | Экспортировать граф в `script.rpy` для Ren'Py |

## 💬 Промпты (Prompts)

Встроенные шаблоны задач — вызываются через `prompts/get`:

| Промпт | Описание |
|---|---|
| `continue_scene` | Продолжить ближайшую незавершённую сцену |
| `review_branch` | Проанализировать ветку и дать рекомендации |
| `add_choice_branch` | Добавить выбор и скелет веток после узла |

## ⚡ Возможности v2.0 (новое)

- **`de_get_characters`** — быстрый справочник персонажей
- **`de_bulk_add_nodes`** — создание цепочек узлов за 1 вызов
- **`de_move_node`** — перемещение / смещение узлов
- **`de_duplicate_node`** — клонирование узла
- **Промпты** (`prompts/list` / `prompts/get`) — готовые рабочие шаблоны
- **`$/cancelRequest`** — корректная обработка отмены запроса
- **Централизованное логирование** через `logging` вместо ручных `sys.stderr.write`
- Исправлен баг `tool_delete_node` (переменная `auto_save` не была объявлена)
- Удалены задвоенные определения `de_load_project` / `de_save_project`
- Унифицированный формат ответов (`✅` / `❌`)
