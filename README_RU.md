## Что такое Dialogue Engine?

**Dialogue Engine** — бесплатный редактор с открытым исходным кодом для написания разветвлённых диалогов и историй. Это **редактор нодового графа**, созданный специально для разработчиков визуальных новелл на Ren'Py. Соединяйте узлы сцен, выборов и музыки на бесконечном холсте, а затем **экспортируйте сценарий в `.rpy`** одним нажатием кнопки.

Больше никакой ручной записи сложных блоков `menu:`. Просто перетаскивайте, соединяйте и экспортируйте.

## Возможности

### Визуальный редактор нод
- **Бесконечный холст** с плавным перемещением на основе физики (стрелки + средняя кнопка мыши)
- **3 типа узлов**: Сцена (диалог), Выбор (ветвление), Музыка/Аудио
- **Отрисовка форматированного текста** с цветовой подсветкой отдельных слов и фраз
- Привязка к сетке

### Редактирование и рабочий процесс
- **Отмена / Повтор** (Ctrl+Z / Ctrl+Y) до 50 шагов
- **Копирование, Вставка, Дублирование** выделенных узлов (Ctrl+C / Ctrl+V / Ctrl+D)
- **Выделение рамкой** перетаскиванием для выбора нескольких узлов
- **Поиск и Замена** по всему содержимому нод
- **Индикатор несохранённых изменений** чтобы не потерять работу

### Экспорт
- **Экспорт в Ren'Py** одним кликом в формат `.rpy`
- Автоматическая генерация `label`, `menu`, `jump`, `play music`
- **Тест-Драйв** запускает сценарий прямо в Ren'Py из редактора

### Система плагинов
Редактор имеет встроенную архитектуру плагинов. Поместите файл `.py` в папку `plugins/` и он автоматически загрузится при запуске.

**Встроенные плагины:**

| Плагин | Описание |
|---|---|
| `renpy_exporter.py` | Экспортирует граф нод в корректный `.rpy` скрипт |
| `interactive_player.py` | Запускает Ren'Py для быстрого тест-драйва |
| `music_plugin.py` | Узлы Музыки/Аудио с режимами BGM и Voice |
| `fs_plugin.py` | Боковая панель файловой системы с перетаскиванием ассетов |
| `grammar_plugin.py` | Проверка грамматики и пунктуации (через API LanguageTool) |
| `word_counter.py` | Статистика количества слов в реальном времени |
| `advanced_scripting.py` | Расширенные типы узлов для скриптинга |
| `core_nodes.py` | Базовое поведение и расширения узлов |
| `flow_nodes.py` | Узлы управления потоком (прыжки, условия) |
| `reload_plugin.py` | Горячая перезагрузка плагинов без перезапуска |

### Сохранение и загрузка
- Проекты сохраняются в читаемом формате **JSON**
- Полная сериализация графа (позиции, содержимое, связи, пользовательские данные)

## Установка

### Требования
- Python **3.8+**
- `tkinter` (входит в стандартную поставку Python для Windows)

### Запуск

```bash
git clone https://github.com/komendant-zero/dialogue-engine.git
cd dialogue-engine
python main.py
```

Внешние зависимости не требуются. Редактор работает только на стандартной библиотеке Python.

## Использование

### Создание истории

1. Нажмите **"Новый Сюжет"** чтобы добавить узел сцены
2. **Дважды кликните** на узел чтобы редактировать содержимое
3. Нажмите **"Новый Выбор"** чтобы добавить узел ветвления
4. **Перетащите от выходного порта** (правая сторона узла) к входному порту другого узла чтобы соединить их

### Навигация

| Действие | Горячая клавиша |
|---|---|
| Перемещение по холсту | Средняя кнопка мыши / Стрелки |
| Выделить несколько | Перетаскивание левой кнопкой (рамка) |
| Отменить | Ctrl+Z |
| Повторить | Ctrl+Y |
| Копировать | Ctrl+C |
| Вставить | Ctrl+V |
| Дублировать | Ctrl+D |
| Удалить выделенное | Delete |
| Редактировать узел | Двойной клик |
| Контекстное меню | Правый клик |

### Экспорт в Ren'Py

1. Откройте ваш проект Ren'Py
2. Нажмите **"Экспорт в Ren'Py"** на панели инструментов
3. Выберите папку `game/` вашего проекта Ren'Py
4. Файл `script.rpy` будет сгенерирован автоматически

### Тест-Драйв

Нажмите **"Тест-Драйв"** чтобы запустить Ren'Py прямо из редактора. При первом запуске вас попросят указать путь к исполняемому файлу Ren'Py.

## Написание своего плагина

Система плагинов проста и основана на событиях. Создайте файл `.py` в папке `plugins/`:

```python
from plugin_system import Plugin

class MyPlugin(Plugin):
    name = "Мой плагин"
    version = "1.0"

    def on_enable(self):
        print("Плагин загружен!")

    def on_event(self, event_type, data=None):
        if event_type == 'setup_ui':
            # Добавьте свою кнопку на панель инструментов
            pass

        elif event_type == 'node_added':
            node = data
            print(f"Новый узел: {node.title}")
```

### Доступные события

| Событие | Когда вызывается |
|---|---|
| `setup_ui` | Строится интерфейс редактора (добавление кнопок на панель) |
| `node_added` | Новый узел добавлен на холст |
| `node_deleted` | Узел удалён |
| `draw_node` | Узел отрисовывается (добавление кастомной графики) |
| `draw_node_content` | Кастомная отрисовка содержимого узла |
| `draw_node_ports` | Кастомная отрисовка портов |
| `calculate_node_size` | Переопределение расчёта размера узла |
| `node_edit_dialog` | Открывается диалог редактирования (добавление полей) |
| `node_edit_save` | Диалог сохраняет данные (чтение полей) |
| `save` | Проект сохраняется |
| `load` | Проект загружается |
