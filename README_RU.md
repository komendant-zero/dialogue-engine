## 📖 Что такое Dialogue Engine?

**Dialogue Engine** — бесплатный визуальный редактор с открытым исходным кодом, созданный специально для сценаристов, нарративных дизайнеров и инди-разработчиков визуальных новелл на **Ren'Py**.

Соединяйте диалоговые блоки, развилки выборов, медиа-спрайты, музыку/SFX и условия на бесконечном холсте — и экспортируйте готовый, чистый скрипт `.rpy` в один клик.

---

## ✨ Ключевые возможности

### 🎨 Визуальный редактор графа
- **Бесконечный холст**: плавное физическое перемещение (стрелки клавиатуры или зажатое колёсико мыши) и точный мультимасштаб (`Ctrl+Колёсико`, `Ctrl+Plus`, `Ctrl+Minus`, `Ctrl+0`).
- **Разнообразие нод**: Сюжетные реплики, ветвящиеся выборы, аудио/SFX, логические условия (`If / Else`), ATL-анимации и Python-скрипты.
- **Подсветка слов и фраз**: Выделение цветом отдельных слов в тексте реплик и настройка цветовых тем для персонажей.
- **Поиск с центрированием камеры (`Ctrl+F`)**: Мгновенный поиск по репликам и именам спикеров с автоматическим переходом камеры к найденному узлу.

### 🛡️ Надёжность и защита данных
- **Фоновое автосохранение и Crash Recovery**: Регулярные снимки состояния каждые 30 секунд в `Save/.autosave/` и предложение восстановить проект после аварийного закрытия.
- **Атомарная запись файлов**: Защита от повреждения JSON при сбоях питания с автоматическим созданием резервной копии `.bak`.
- **Глубокая история Undo / Redo**: 50 шагов отмены/повтора (`Ctrl+Z` / `Ctrl+Y`) с поддержкой группового копирования, вставки и дублирования (`Ctrl+C` / `Ctrl+V` / `Ctrl+D`).

### ⚙️ Модульная архитектура (v2.0)
- `core/`: Независимые модели данных, топология графа, детекция циклов и валидация связей.
- `ui/`: Адаптивный холст Tkinter, цветовые схемы и модальные диалоги.
- `export/`: Генератор Ren'Py кода, работающий как в GUI, так и в headless-режиме (без интерфейса).
- `plugin_system/`: Подсистема плагинов с изоляцией ошибок (Error Boundary), защитой от дублирования и мониторингом здоровья.

## 🧩 Встроенные плагины

| Плагин | Описание |
|---|---|
| `renpy_exporter.py` | Экспорт нодового графа в структурированный `.rpy` скрипт |
| `condition_node.py` | Логические развилки (`If / Else`) с портами True и False |
| `graph_validator.py` | Диагностика сценария: поиск тупиков, висячих веток и пустых выборов |
| `quick_playtest.py` | Встроенный плеер диалогов для быстрого тестирования без запуска Ren'Py |
| `interactive_player.py` | Мгновенный тест-драйв в установленном Ren'Py прямо из редактора |
| `media_node.py` | Фоновые изображения, спрайты и анимированные GIF |
| `music_plugin.py` | Музыкальные и звуковые узлы с режимами BGM, SFX и Voice |
| `pause_plugin.py` | Настраиваемые паузы по времени и по клику игрока |
| `auto_layout.py` | Автоматическая расстановка и выравнивание нод по сетке (`Ctrl+L`) |
| `word_counter.py` | Статистика слов и строк проекта в реальном времени |
| `advanced_scripting.py` | Блоки чистого Python-кода и прямых инструкций Ren'Py |

> 📚 Хотите создать свой тип узла или инструмент? Ознакомьтесь с [Руководством разработчика плагинов (Public API)](docs/PLUGIN_API.md).

## 🚀 Быстрый старт

### Требования
- Python **3.10+** (протестировано на 3.10, 3.11, 3.12)
- `tkinter` (входит в стандартную поставку Python для Windows и macOS; для Linux: `sudo apt install python3-tk`)
- Опционально: `Pillow>=9.0.0` для предпросмотра GIF

### Установка и запуск

```bash
git clone https://github.com/komendant-zero/dialogue-engine.git
cd dialogue-engine
pip install -r requirements.txt
python main.py
```

### Запуск тестов

```bash
python -m unittest discover tests -v
```
