Надёжность ядра

Error Boundary & Безопасность

Почему падение стороннего скрипта никогда не приведёт к потере вашего сценария.

🛡️

Error Boundary

Все вызовы событий on_event() обёрнуты в защищённые контексты перехвата исключений. Ошибка в плагине логируется, но не прерывает работу GUI-цикла и других расширений.

🩺

Health Check & Auto-Disable

Менеджер плагинов отслеживает количество последовательных ошибок. При превышении порога нестабильный плагин переводится в статус ERROR и отключается.

⚡

Zero Overhead

Плагины подписываются только на интересующие их события (рендеринг, контекстное меню, экспорт). При отсутствии подписчиков накладные расходы равны нулю.

Каталог

Встроенные плагины

Поставляются "из коробки" и активируются автоматически при старте редактора.

renpy_exporter.py Core Export

Превращает визуальный граф диалогов в чистый и читаемый исходный код script.rpy. Поддерживает структурирование по меткам (labels), блоки выборов, ветвление if / elif / else, вызовы jump и call.

Ключевые возможности:
  • Экспорт как через GUI диалог, так и через headless CLI / MCP
  • Автогенерация идентификаторов меток по номерам глав и сцен
  • Поддержка кастомных отступов и Ren'Py синтаксиса
ai_live_sync.py AI Integration

Слушает локальный TCP-сокет на порту 48123. Обеспечивает мгновенный отклик холста при выполнении команд MCP-сервера внешними языковыми моделями.

Ключевые возможности:
  • Анимация спавна узлов без блокировки главного потока GUI
  • Плавная авто-фокусировка камеры на свежесозданных репликах
  • Обновление статусной строки при активности AI Copilot
condition_node.py Narrative Logic

Реализует узлы проверки условий. Добавляет два цветных выходных порта: зелёный (True) и красный (False/Else), позволяя строить сложные нелинейные развилки сюжета.

Ключевые возможности:
  • Удобный редактор выражения с подсветкой синтаксиса
  • Поддержка составных условий: and, or, not
  • Автоматическая трансляция в Ren'Py конструкцию if ...: else:
graph_validator.py Diagnostics

Сканирует топологию графа на предмет логических ошибок перед релизом или экспортом новеллы. Предупреждает о сюжетных тупиках и битых связях.

Ключевые возможности:
  • Поиск "висячих" узлов без входящих линий (сироты)
  • Поиск забытых вариантов в узлах выбора без продолжения
  • Детекция бесконечных замкнутых циклов без выхода
auto_layout.py Canvas Layout

Интеллектуальная автораскладка графа по нажатию Ctrl+L. Расставляет узлы по слоям (Sugiyama-like hierarchy) слева направо с оптимальными отступами.

Ключевые возможности:
  • Минимизация пересечений соединительных линий
  • Равномерное распределение параллельных сюжетных веток
  • Анимированное перемещение узлов на новые позиции
quick_playtest.py Testing

Встроенное окно симулятора новеллы. Позволяет мгновенно начать чтение сценария с любого выбранного узла графа без запуска тяжеловесного Ren'Py движка.

Ключевые возможности:
  • Интерактивные кнопки выбора и переход по веткам
  • Отслеживание значений игровых переменных в реальном времени
  • Подсветка текущего узла на холсте по мере прохождения
interactive_player.py Ren'Py Launcher

Связующее звено между Dialogue Engine и установленным дистрибутивом Ren'Py. Экспортирует сценарий и запускает игровой процесс одной кнопкой.

Ключевые возможности:
  • Автоматический поиск исполняемого файла renpy.exe
  • Быстрый перезапуск игры с сохранением позиции
  • Вывод консольных логов Ren'Py в интерфейс редактора
media_node.py Visual Assets

Управление графическими ассетами новеллы: смена фонов (scene), появление и скрытие персонажей (show/hide), а также превью спрайтов прямо на узле.

Ключевые возможности:
  • Миниатюры изображений и GIF на карточке узла
  • Настройка позиций отображения (left, right, center, truecenter)
  • Быстрый выбор из каталога game/images/
music_plugin.py Audio

Полный контроль над звуковым оформлением: фоновая музыка, звуковые эффекты (SFX), озвучка персонажей (Voice) и команды плавного затухания.

Ключевые возможности:
  • Режимы bgm, sfx, voice, stop
  • Параметры fadein и fadeout в секундах
  • Предварительное прослушивание треков в редакторе
animations_plugin.py ATL FX

Поддержка Ren'Py Animation & Transformation Language (ATL). Позволяет вставлять эффекты тряски экрана, плавные переходы (dissolve), вспышки и зум.

Ключевые возможности:
  • Пресеты популярных переходов (fade, dissolve, vpunch, hpunch)
  • Кастомный редактор блоков ATL трансформаций
  • Привязка анимаций к конкретным медиа-узлам
word_counter.py Analytics

Аналитика объёма сценария: подсчёт символов, слов, реплик и приблизительного времени чтения как для всего проекта, так и по отдельным персонажам.

Ключевые возможности:
  • Детальная статистика реплик по каждому герою новеллы
  • Оценка хронометража прохождения игры
  • Быстрый просмотр метрик в статусной строке
advanced_scripting.py Scripting

Узлы прямого скриптинга: произвольный Python-код (блок python:) и однострочные модификации переменных ($ flags['met_hero'] = True).

Ключевые возможности:
  • Полноценный многострочный редактор кода
  • Поддержка глобальных списков и словарей Ren'Py
  • Безопасная сериализация кода внутри JSON проекта
reload_plugin.py Hot Reload

Файловый наблюдатель (Live Watcher): отслеживает внешние изменения JSON-файла проекта и автоматически обновляет холст без необходимости перезапуска редактора.

Ключевые возможности:
  • Бесшовное сотрудничество сценаристов через системы контроля версий (Git)
  • Защита от конфликтов при одновременной правке
  • Звуковое или визуальное уведомление об обновлении
mcp_plugin.py MCP Status

Визуальный индикатор состояния MCP-сервера в шапке редактора. Показывает текущий статус подключения LLM, порт 48123 и количество выполненных ИИ-запросов.

Ключевые возможности:
  • Кнопка быстрого перезапуска MCP-сервера
  • Лог последних вызванных инструментов
  • Индикация активных сессий AI-ассистентов
pause_plugin.py Flow Control

Узлы временных задержек и ожиданий клика игрока. Необходимы для создания драматических пауз, ожидания завершения фоновых звуков или анимаций.

Ключевые возможности:
  • Фиксированная пауза (в секундах)
  • Ожидание нажатия пользователем
  • Трансляция в вызов renpy.pause()
fs_plugin.py Asset Browser

Встроенный браузер файлов проекта. Позволяет перетаскивать графические и аудиофайлы прямо из боковой панели на холст для создания соответствующих узлов.

Ключевые возможности:
  • Быстрый предпросмотр изображений и воспроизведение звука
  • Drag & Drop на бесконечный холст
  • Фильтрация по расширениям: .png, .jpg, .ogg, .mp3, .rpy
Кастомизация

Как установить сторонний плагин

Установка пользовательских модулей происходит без сборки и компиляции.

1

Скачайте файл плагина

Плагин представляет собой обычный файл Python (например, custom_export.py).

2

Скопируйте в plugins/

Поместите файл в папку plugins/ в корневой директории Dialogue Engine.

3

Перезапустите редактор

Менеджер плагинов автоматически обнаружит класс-наследник Plugin и инициализирует его.
