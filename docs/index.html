Установка и запуск

Быстрый старт за 2 минуты

Dialogue Engine написан на чистом Python и использует стандартный Tkinter — никаких тяжёлых фреймворков и веб-контейнеров.

1. Клонирование и зависимости

Требуется Python 3.10 или новее. Установите зависимости одной командой:

bash 
# Клонирование репозитория
git clone https://github.com/komendant-zero/dialogue-engine.git
cd dialogue-engine

# Запуск редактора (графический интерфейс)
python main.py

# Или открытие конкретного файла проекта:
python main.py D:/projects/MyNovel/game/story.json

2. Запуск MCP AI Сервера

Для подключения ассистентов (Antigravity / Claude / Cursor) запустите сервер по протоколу stdio:

bash 
# Запуск MCP-сервера со стандартным вводом/выводом
python mcp_server.py D:/projects/MyNovel/game/story.json

# Проверка работоспособности (тестовый запуск)
python mcp_server.py --test
💡
Сервер автоматически подключается к запущенному редактору через локальный порт 48123 и обновляет холст на лету!
Справочник

Типы узлов графа

Каждый узел представляет конкретное игровое событие или реплику в сценарии визуальной новеллы.

Тип (type) Назначение Порты выхода Параметры и Custom Data В Ren'Py
story Реплика персонажа или нарративное описание сцены 1 выход character (спикер или #Сцена), content (текст), header_text_color e "Привет, мир!"
choice Выбор игрока с N вариантами ответа N выходов (по варианту) Каждая строка в content формирует отдельный порт выхода menu: "Вариант 1": ...
condition Ветвление логики по условию (If / Else) 2 выхода (0=True, 1=False) condition (выражение, напр. points >= 10) if points >= 10: ... else:
music Управление фоновой музыкой, SFX или голосом 1 выход (сквозной) music_mode (bg, sfx, voice, stop), fadein, fadeout play music "audio/bgm.ogg"
media Смена фона (scene), спрайта персонажа (show/hide), GIF 1 выход image_path, display_mode (scene/show/hide), теги позиции scene bg room / show eileen
label Метка точки входа или переход (Jump/Call) 1 выход label_name (имя метки в скрипте) label chapter_1:
variable Присвоение или модификация переменной 1 выход var_name, operator (=, +=, -=), var_value $ karma += 1
animation ATL-анимация перехода, шейка экрана или трансформация 1 выход atl_code, target_displayable with dissolve / with hpunch
python_code Произвольный блок Python кода в логике сцены 1 выход code (многострочный скрипт) python: блок
pause Пауза или ожидание клика игрока 1 выход duration (секунды или бесконечность до клика) $ renpy.pause(2.0)

Горячие клавиши

Управляйте холстом и узлами без отрыва рук от клавиатуры.

Комбинация Действие
Ctrl + S Быстрое сохранение проекта с созданием резервной копии
Ctrl + O Открыть существующий файл проекта .json
Ctrl + F Поиск узла по тексту, спикеру или ID
Ctrl + Z / Ctrl + Y Отмена / Повтор действия (Undo / Redo)
Ctrl + L Интеллектуальная автораскладка графа слева направо
Комбинация / Мышь Действие
Ctrl + C / Ctrl + V Копирование и вставка выбранных узлов
Ctrl + D Быстрое дублирование узла со сдвигом вправо
Delete Удаление выбранного узла и всех его связей
Ctrl + Колёсико Плавное масштабирование (Zoom In / Out)
ПКМ / ДКМ Контекстное меню холста / Редактирование узла
