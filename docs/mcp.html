Подключайте современные большие языковые модели напрямую к холсту диалогов. 22 специализированных инструмента позволяют читать сюжет, ветвить истории и спавнить узлы на глазах у пользователя.

Как работает экосистема MCP

Полный цикл: от промпта пользователя к LLM до появления нового узла на холсте редактора.

1. Двусторонний stdio

Обмен сообщениями стандартизирован через JSON-RPC 2.0 (Model Context Protocol). Поддерживается Windows с автоматическим переключением stdin/stdout на UTF-8.

2. Умное автопозиционирование

Сервер сам вычисляет оптимальные координаты X/Y: реплики размещаются аккуратно правее родительского узла с правильными отступами, не перекрывая соседние ветки.

3. Live Sync без перезапуска

При каждом действии ИИ сервер отправляет TCP-дейтаграмму на 127.0.0.1:48123. Редактор моментально отрисовывает новый узел и плавно центрирует на нём камеру.

Интеграция

Быстрое подключение

Добавьте блок сервера в конфигурационный файл вашего AI-клиента.

mcp_settings.json / claude_desktop_config.json 
{
  "mcpServers": {
    "dialogue-engine": {
      "command": "python",
      "args": [
        "D:/DE/mcp_server.py",
        "D:/projects/MyNovel/game/story.json"
      ],
      "env": {
        "PYTHONIOENCODING": "utf-8"
      }
    }
  }
}
⚠️
Важное замечание: Переменная PYTHONIOENCODING=utf-8 обязательна для корректной передачи кириллических реплик через стандартный ввод/вывод в среде Windows.
Каталог инструментов

22 MCP Инструмента

Полный набор функций для автоматического управления сюжетом, доступный языковой модели.

📁 1. Управление проектом 3 инструмента
de_load_project Project Lifecycle

Загрузить указанный файл проекта Dialogue Engine (.json) в память сервера. Если путь не передан, открывает последний активный файл.

Параметры:
  • file_path (string, optional) — Абсолютный путь к целевому JSON-файлу.
de_save_project Project Lifecycle

Сохранить граф на диск с автоматическим созданием резервной копии .bak.

Параметры:
  • target_path (string, optional) — Путь назначения. По умолчанию перезаписывает открытый файл.
de_reload_server Maintenance

Перезагрузить процесс MCP-сервера для подхвата свежих изменений в коде плагинов и модулей.

Параметры: отсутствует (пустой объект)
🔍 2. Анализ и инспекция графа 6 инструментов
de_get_stats Analysis

Возвращает комплексную сводку: количество узлов, связей, распределение по типам, персонажи, стартовые точки, листья и изолированные узлы.

Параметры: отсутствует
de_get_characters Analysis

Возвращает список всех персонажей сценария с количеством произнесённых реплик и присвоенным hex-цветом плашки.

Параметры: отсутствует
de_find_leaf_endpoints Analysis

Находит все листовые узлы (тупики сценария без исходящих связей). Ключевой инструмент для AI-продолжения недописанных сцен.

Параметры: отсутствует
de_get_node Analysis

Получить детальные данные конкретного узла: спикер, текст, координаты, custom_data, входящие и исходящие связи с номерами портов.

Параметры:
  • node_id (string) Обязательный — 13-значный числовой ID узла.
de_search_nodes Analysis

Полнотекстовый поиск по узлам с фильтрацией по персонажу и типу узла.

Параметры:
  • query (string, optional) — Подстрока в тексте или заголовке.
  • character (string, optional) — Имя спикера.
  • node_type (string, optional) — Фильтр типа (story, choice, condition, etc.).
  • limit (integer, optional) — Лимит вывода (по умолчанию 20).
de_trace_branch Analysis

Трассирует сюжетную ветку от узла до листьев, формируя отформатированный древовидный сценарий с учётом ветвлений.

Параметры:
  • start_node_id (string, optional) — Старт ветки (по умолчанию — со всех корневых узлов).
  • max_depth (integer, optional) — Предельная глубина обхода (по умолчанию 30).
✨ 3. Создание узлов 5 инструментов
de_add_story_node Creation

Добавить сюжетную реплику или описание. Автоматически рассчитывает координаты X/Y справа от родителя и сохраняет проект.

Параметры:
  • character (string) Обязательный — Имя спикера или #Сцена для нарратива.
  • content (string) Обязательный — Текст реплики.
  • connect_from_id (string, optional) — ID родителя для связки.
  • connect_out_idx (integer, optional) — Порт родителя (0 по умолчанию).
  • x, y (number, optional) — Точные координаты (если не заданы — авто).
  • auto_save (boolean, optional) — Автосохранение (true).
de_add_choice_node Creation

Создать узел выбора с несколькими вариантами ответов. Каждый вариант получает собственный выходной порт.

Параметры:
  • choices (array of strings) Обязательный — Массив текстов выборов.
  • title (string, optional) — Заголовок узла (по умолчанию «Выбор»).
  • connect_from_id (string, optional) — Родительский узел.
  • connect_out_idx (integer, optional) — Порт родителя.
de_add_condition_node Creation

Создать узел ветвления по выражению (например, trust > 5). Генерирует 2 порта выхода: 0=True, 1=False (Else).

Параметры:
  • condition (string) Обязательный — Python-выражение для Ren'Py.
  • title (string, optional) — Название узла.
  • connect_from_id (string, optional) — Родительский узел.
de_add_music_node Creation

Добавить музыкальный узел или SFX. Поддерживает вставку в разрыв между двумя уже соединёнными узлами через connect_to_id.

Параметры:
  • music_file (string) Обязательный — Путь к файлу (напр. audio/ambient.ogg).
  • music_mode (string: bg|sfx|voice|stop) — Режим воспроизведения.
  • connect_to_id (string, optional) — Узел, перед которым встраивается музыка.
  • fadein, fadeout (number, optional) — Время нарастания/затухания в секундах.
de_bulk_add_nodes Batch Operation

Пакетное создание целых сцен и сюжетных арок за один сетевой запрос. Принимает список дескрипторов узлов и соединений.

Параметры:
  • nodes (array of objects) Обязательный — Список спецификаций узлов с типом и параметрами.
  • auto_save (boolean, optional) — Автосохранение после пакетной вставки.
✏️ 4. Редактирование и трансформация 4 инструмента
de_update_node Mutation

Модифицирует любые свойства существующего узла: текст, персонажа, тип, координаты или данные словаря custom_data.

Параметры:
  • node_id (string) Обязательный — ID обновляемого узла.
  • character / title / content (string, optional) — Новые текстовые поля.
  • custom_data (object, optional) — Слияние словаря кастомных полей.
de_move_node Layout

Переместить узел на абсолютные координаты (x, y) либо со сдвигом по дельте (delta_x, delta_y).

Параметры:
  • node_id (string) Обязательный
  • x, y (number, optional) — Абсолютные координаты.
  • delta_x, delta_y (number, optional) — Относительный сдвиг.
de_duplicate_node Clone

Создаёт точную копию узла со всеми параметрами со сдвигом вправо (+240px по умолчанию) без привязки связей.

Параметры:
  • node_id (string) Обязательный — ID исходного узла.
  • offset_x, offset_y (number, optional) — Смещение дубликата.
de_delete_node Deletion

Удаляет узел из графа и аккуратно подчищает все входящие и исходящие линии соединений.

Параметры:
  • node_id (string) Обязательный
  • auto_save (boolean, optional)
🔗 5. Управление связями 2 инструмента
de_connect_nodes Wiring

Соединить выходной порт узла-источника со входом целевого узла.

Параметры:
  • from_node (string) Обязательный — ID исходного узла.
  • to_node (string) Обязательный — ID целевого узла.
  • out_idx (integer, optional) — Индекс выходного порта (0 по умолчанию).
de_disconnect_nodes Wiring

Разорвать соединение между узлами по номеру выхода или удалить все связи с порта.

Параметры:
  • from_node (string) Обязательный
  • out_idx (integer, optional) — Индекс выхода (0 по умолчанию).
  • to_node (string, optional) — Конкретный целевой узел.
🚀 6. Проверка и экспорт 2 инструмента
de_validate_graph Validation

Комплексная диагностика: битые ссылки, висячие условия, изолированные узлы, циклы и пустые реплики.

Параметры: отсутствует
de_export_renpy Export

Автоматическая компиляция графа в рабочий script.rpy с разметкой для движка Ren'Py.

Параметры:
  • output_dir (string, optional) — Директория игры game/ проекта Ren'Py.
Сценарии использования

Встроенные MCP Промпты

Готовые контекстные инструкции для мгновенного выполнения нарративных задач.

Prompt

continue_scene

Находит все незавершённые листья сюжета (или начинает от переданного leaf_id) и генерирует логичное нарративное продолжение реплик.

Prompt

review_branch

Трассирует ветку от start_node_id и выполняет глубокую редакторскую вычитку: темп повествования, характер персонажей и сюжетные дыры.

Prompt

add_choice_branch

Создаёт узел развилки с num_choices вариантами после parent_id и автоматически генерирует скелеты сцен для каждого пути.

Ресурсы MCP

Единый ресурс активного проекта

de://project/active application/json

Предоставляет AI-клиенту полный слепок текущего графа в виде JSON. Позволяет модели мгновенно загрузить всю топологию проекта в свой контекст для сквозного анализа сценария.

Интерактивность

Механизм Live Sync (Порт 48123)

Как сервер и редактор общаются во время работы нейросети.

Когда AI вызывает любой создающий или модифицирующий инструмент (например, de_add_story_node), MCP Server не просто обновляет JSON на диске — он отправляет сокетное уведомление на локальный TCP-порт 48123.

  • Редактор получает команду node_spawn
  • Создаётся плавная анимация появления узла
  • Автоматически рисуется соединительная кривая Безье
  • Камера холста плавно центрируется на созданном узле
Пакет синхронизации TCP 
{
  "action": "node_spawn",
  "node": {
    "id": "8392019485712",
    "type": "story",
    "title": "Алиса",
    "content": "Мы наконец нашли вход в лабораторию...",
    "x": 840.0,
    "y": 220.0
  },
  "connection": {
    "from": "8392019485001",
    "out_idx": 0,
    "to": "8392019485712"
  },
  "focus": true
}
