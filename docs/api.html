Модели данных

Класс NodeData

Определён в core/models.py как чистый @dataclass. Представляет один узел графа.

Поле Тип По умолчанию Описание
id str 13-значный ID Уникальный строковый идентификатор узла, генерируемый через uuid.uuid4().int.
x float 0.0 Горизонтальная координата верхнего левого угла узла на бесконечном холсте.
y float 0.0 Вертикальная координата верхнего левого угла узла на холсте.
width float 180.0 Ширина карточки узла в пикселях холста.
height float 100.0 Высота карточки узла (может пересчитываться динамически по объёму текста).
title str "" Заголовок узла или имя персонажа (например, "Алиса" или "#Сцена").
content str "" Основное текстовое наполнение: реплика диалога, строки выбора через перевод строки или код.
node_type str "story" Тип узла: story, choice, condition, music, media и т.д.
mode str "standard" Режим отображения узла.
custom_data Dict[str, Any] {} Словарь произвольных пользовательских параметров (цвета плашки, тайминги, флаги).
is_character Optional[bool] None Признак спикера: если None, вычисляется автоматически по отсутствию символа # в заголовке.

Класс ConnectionData

Описывает направленное соединение между портом выхода одного узла и входом другого.

Поле Тип Описание
from_node str ID узла-источника.
out_idx int Индекс выходного порта (0 для обычной реплики, 0..N-1 для вариантов выбора или ветвлений).
to_node str ID целевого узла-приёмника.
Методы ядра

Методы класса GraphModel

Доступен через self.editor.graph или экземпляр проекта.

Метод / Свойство Сигнатура Описание
nodes @property -> List[NodeData] Возвращает список всех узлов текущего графа.
connections @property -> List[ConnectionData] Возвращает список всех связей графа.
get_node() get_node(node_id: str) -> Optional[NodeData] Возвращает объект узла по его ID или None.
add_node() add_node(node: NodeData) -> NodeData Добавляет узел в граф и возвращает его.
remove_node() remove_node(node_id: str) -> Optional[NodeData] Удаляет узел и все связанные входящие/исходящие линии.
add_connection() add_connection(from_node: str, out_idx: int, to_node: str) -> bool Создаёт связь. Автоматически заменяет существующую связь с того же выхода при моногамном порте.
remove_connection() remove_connection(from_node: str, out_idx: int, to_node: Optional[str] = None) -> bool Удаляет связь по порту выхода или точечно к целевому узлу.
get_outgoing() get_outgoing(node_id: str) -> List[ConnectionData] Возвращает все исходящие связи узла.
get_incoming() get_incoming(node_id: str) -> List[ConnectionData] Возвращает все входящие связи узла.
get_start_nodes() get_start_nodes() -> List[NodeData] Ищет стартовые узлы: по заголовку (start/старт/начало) или узлы без входящих линий.
clear() clear() -> None Полностью очищает граф.
Событийная модель

События plugin_system/events.py

Метод on_event(self, event_type: str, data: Any) принимает события со следующими полезными нагрузками:

Событие (event_type) Передаваемые данные (data) Назначение
setup_ui toolbar: Frame Инициализация плагина при загрузке UI: можно добавить свои кнопки на панель инструментов.
context_menu {'target': Node, 'x': float, 'y': float, 'menu': Menu} Клик ПКМ по холсту или узлу: добавление кастомных пунктов контекстного меню.
autosave_tick None Периодический тик автосохранения (каждые 30 секунд).
project_loaded project_data: ProjectData Файл проекта успешно загружен и отрисован на холсте.
project_saved filepath: str Проект успешно записан на диск.
node_added node: NodeData На холст добавлен новый узел.
node_deleted node: NodeData Узел был удалён пользователем или скриптом.
node_edit_dialog {'node': Node, 'frame': Frame, 'dialog': Toplevel} Открыт диалог редактирования узла: можно встроить кастомные поля ввода.
node_edit_save {'node': Node} Сохранение изменений из диалога редактирования.
draw_node {'node': Node, 'canvas': Canvas} Событие рендеринга узла на Canvas.
draw_node_content {'node': Node, 'canvas': Canvas, 'handled': bool} Кастомный рендеринг содержимого карточки узла (спрайты, иконки).
draw_node_ports {'node': Node, 'canvas': Canvas, 'handled': bool} Отрисовка портов входа и выхода.
calculate_node_size {'node': Node, 'base_h': int, 'display_content': str, 'height': int, 'handled': dict} Динамический расчёт габаритов карточки узла.
renpy_export_init {'file': file, 'nodes': list, 'connections': list, 'export_dir': str} Старт процесса генерации скрипта Ren'Py.
renpy_export_check {'node': Node, 'skip': bool} Проверка перед экспортом: плагин может установить skip = True, чтобы пропустить узел.
renpy_export_node {'node': Node, 'file': file, 'connections': list, 'export_dir': str, 'handled': bool} Генерация Ren'Py-кода для специфического кастомного узла.
Практика

Пример минимального плагина

Создание плагина счётчика выборов, добавляющего кнопку на панель инструментов и перехватывающего добавление узлов.

plugins/choice_tracker.py 
from plugin_system.base import Plugin, PluginManifest
from plugin_system.events import EVENT_SETUP_UI, EVENT_NODE_ADDED, EVENT_CONTEXT_MENU
import tkinter as tk
from tkinter import messagebox


class ChoiceTrackerPlugin(Plugin):
    name = "Choice Tracker"
    version = "1.0.0"
    author = "Community Developer"
    description = "Подсчитывает развилки и выводит статистику выборов сценария."
    min_engine_version = "2.0.0"

    def on_enable(self) -> None:
        # Вызывается при загрузке плагина
        self.choice_count = 0
        print(f"[{self.name}] Успешно активирован.")

    def on_disable(self) -> None:
        print(f"[{self.name}] Деактивирован.")

    def on_event(self, event_type: str, data: any = None) -> None:
        if event_type == EVENT_SETUP_UI:
            # Добавляем кнопку на панель инструментов (toolbar)
            toolbar = data
            btn = tk.Button(
                toolbar,
                text="📊 Анализ выборов",
                command=self.show_stats,
                bg="#21262d",
                fg="#00b4ff",
                relief=tk.FLAT
            )
            btn.pack(side=tk.LEFT, padx=4, pady=2)

        elif event_type == EVENT_NODE_ADDED:
            node = data
            if node.node_type == "choice":
                self.choice_count += 1

        elif event_type == EVENT_CONTEXT_MENU:
            # Добавляем пункт в контекстное меню ПКМ
            menu = data.get("menu")
            if menu:
                menu.add_separator()
                menu.add_command(label="Быстрая статистика выборов", command=self.show_stats)

    def show_stats(self) -> None:
        total_nodes = len(self.editor.graph.nodes)
        choices = [n for n in self.editor.graph.nodes if n.node_type == "choice"]
        msg = f"Всего узлов: {total_nodes}\nУзлов развилок (choice): {len(choices)}"
        messagebox.showinfo("Статистика выборов", msg)
✨
Готово к запуску: Сохраните приведённый код как plugins/choice_tracker.py. Редактор автоматически подхватит его при старте, добавит кнопку на верхнюю панель и зарегистрирует пункт контекстного меню.
